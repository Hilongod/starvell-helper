# Политика конфиденциальности расширения Starvell Helper

_Дата вступления в силу: 14 июля 2026 г._

## Введение
Расширение Starvell Helper разработано для автоматизации действий на сайте Starvell.com. Мы уважаем вашу конфиденциальность и не собираем, не храним и не передаём ваши личные данные.

## Какие данные собираются?
Расширение **не собирает**:
- личную информацию (имя, адрес, телефон, email);
- финансовые или платёжные данные;
- данные для аутентификации (пароли, PIN-коды);
- историю посещений или поиска;
- содержимое ваших сообщений или любые другие личные данные.

Вся информация, которая используется для работы расширения (настройки, логи, статистика поднятий), сохраняется **исключительно локально** в вашем браузере с помощью `chrome.storage.local`. Эти данные никогда не покидают ваше устройство и не передаются третьим лицам.

## Как расширение взаимодействует с Starvell.com?
Расширение отправляет запросы к открытым API сайта `starvell.com` (например, `/api/offers/bump`, `/api/orders/list`, `/api/support/tickets`) для выполнения функций автоподнятия и автотикетов. Эти запросы используют вашу активную сессию в браузере (cookie), но расширение не сохраняет и не передаёт их куда-либо ещё.

## Сторонние сервисы
Расширение не использует сторонние сервисы аналитики, трекинга или рекламы. Все функции выполняются локально.

## Изменение политики
Мы можем обновлять эту политику. Все изменения будут публиковаться в этом репозитории.
