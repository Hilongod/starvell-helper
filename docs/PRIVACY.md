# Политика конфиденциальности расширения Starvell Helper

_Версия расширения: 2.1.4._  
_Дата обновления политики: 11 октября 2026 г._

## 1. Назначение и область действия

**Starvell Helper** (далее — «Расширение») автоматизирует действия продавца на сайте `starvell.com`: поднятие предложений, обращения в поддержку, отображение статистики и настройку оформления сайта.

Расширение обрабатывает сведения вашего аккаунта Starvell и сохраняет часть из них локально в браузере. Рабочие запросы отправляются в Starvell от имени вашей активной сессии. Разработчик не получает эти данные автоматически: в коде нет сервиса сбора данных для разработчика, аналитики, телеметрии или рекламных трекеров.

Отдельно возможна загрузка изображений с внешних сайтов, если вы используете такой фон или его предпросмотр. Настоящая политика описывает работу Расширения; обработка данных самим Starvell, браузером и выбранными внешними сервисами регулируется их собственными правилами.

## 2. Какие данные обрабатываются

| Данные | Назначение | Обработка и хранение |
|---|---|---|
| Имя пользователя и ID аккаунта Starvell | Определение текущего продавца и привязка его расписания | Сохраняются локально |
| ID и названия игр, сервисов и категорий, доступные счётчики лотов, время проверки профиля | Формирование актуального списка категорий для поднятия | Сохраняются в локальном каталоге и обновляются при чтении профиля |
| Время успешного поднятия, сроки следующих попыток, cooldown и общие ограничения запросов | Адаптивное расписание и восстановление после перезапуска | Сохраняются локально для текущего владельца аккаунта |
| Идентификатор запуска, ID рабочей вкладки и срок завершения | Защита от повторного поднятия из нескольких вкладок | Сохраняются локально на время управления запуском |
| Сессионный ключ `session` — Secret Key / Session Key | Проверка авторизации, отображение и копирование ключа | Временно находится в памяти страницы; автоматически в настройки не записывается |
| Номера, статусы, даты и суммы заказов, категории, имена или ID покупателей; баланс и суммы выводов из кошелька | Расчёт статистики и поиск заказов для обращений в поддержку | Загружаются из Starvell и обрабатываются в памяти страницы; полные ответы в локальные настройки не записываются |
| Настройки функций, ссылка на фон, прозрачность, звуки, свечение, уведомления, параметры и текст шаблона автотикетов | Применение пользовательских настроек | Сохраняются локально; текст шаблона сохраняется в указанном пользователем виде |
| Счётчики поднятий и ошибок, результаты запусков и журнал событий | Отображение работы и диагностика ошибок | Сохраняются локально; журнал ограничен 200 последними записями |

Ответы страниц и API Starvell могут содержать дополнительные сведения об аккаунте. Для каталога автоподнятия сохраняются перечисленные выше поля, а не полный ответ профиля. В журнал могут попадать ID игр, сведения о выполненных действиях и текст ошибок, полученный от Starvell.

Расширение не запрашивает у пользователя пароль, PIN-код, код двухфакторной аутентификации или банковские реквизиты. Оно не запрашивает геолокацию, историю посещений других сайтов или историю чатов. Финансовые суммы из Starvell используются для статистики и не отправляются разработчику.

## 3. Как используются данные

**Автоподнятие.** Расширение читает профиль текущего продавца, определяет игры, сервисы и категории с предложениями и отправляет запросы `/api/offers/bump` с `gameId` и `categoryIds`. ID отдельных лотов в этот запрос не включаются.

При включённом автоподнятии плановая проверка профиля выполняется раз в **30 минут**. Профиль также перечитывается перед поднятием, при открытии панели и при повторных попытках после ошибок. Новые игры и категории обнаруживаются при ближайшем чтении профиля. Базовый интервал по умолчанию — **2 часа плюс 1 минута запаса** после успеха. При серверном cooldown учитывается сообщённый остаток ожидания плюс 1 минута. Каталог и сроки сохраняются локально для восстановления расписания.

**Статистика.** По запросу пользователя загружаются заказы через `/api/orders/list` и страницы кошелька Starvell. На их основе рассчитываются суммы продаж, баланс, суммы выводов, количество заказов, возвратов и покупателей, а также другие показатели панели.

**Обращения в поддержку.** При ручном запуске или включённой функции автотикетов Расширение находит заказы со статусом `CREATED`, соответствующие выбранному сроку ожидания, и отправляет обращения через `/api/support/create`. Starvell получает тему, текст обращения, номера заказов и необходимые параметры формы. Пользовательский шаблон включается в обращение с подстановкой данных заказов. Локально сохраняются настройки и время отправки; результаты могут отражаться в журнале.

**Оформление и уведомления.** Настройки используются для изменения фона, звуков и свечения, а также для уведомлений браузера о результатах работы.

## 4. Сессионный ключ и авторизация

Cookie `session` создаёт и хранит Starvell в браузере. Расширение читает её через фоновый процесс для проверки авторизации и функции Session Key. Если основной способ недоступен, загрузчик ключа проверяет доступные cookie страницы и данные авторизации в её `__NEXT_DATA__`.

Полученный ключ временно хранится в памяти страницы. По умолчанию он отображается в замаскированном виде; пользователь может показать его или нажать «Копировать». При копировании значение попадает в системный буфер обмена. Код Расширения не выводит значение ключа в журнал или консоль и не сохраняет его автоматически в `chrome.storage.local`.

Запросы к Starvell используют активную браузерную сессию: соответствующие cookie передаёт браузер. Для автоподнятия не требуется вручную извлекать или копировать текст Secret Key. Расширение не отправляет ключ на сервер разработчика и не подставляет его в запросы внешних фоновых изображений. Дальнейшее использование скопированного ключа в других приложениях выполняет сам пользователь.

## 5. Получатели данных и внешние запросы

**Starvell.** Запросы профиля, поднятия, заказов, кошелька и поддержки адресованы `starvell.com`. Сервис получает авторизованные запросы и данные, необходимые для выбранного действия. Обращения и их содержание сохраняются на стороне Starvell по правилам сервиса.

**Серверы изображений.** Если вы вводите внешнюю ссылку на фон или выбираете соответствующий пресет, браузер может загрузить изображение уже при предпросмотре и затем при применении фона. Встроенные пресеты используют, в частности, Steamusercontent, Postimg и Unsplash. Сервер изображения получает обычный запрос браузера, включая IP-адрес и технические параметры запроса; сведения о странице-источнике зависят от политики браузера и сайта. Расширение не добавляет в эти запросы каталог продавца, статистику заказов или сессионный ключ Starvell.

**Разработчик Расширения.** Автоматическая передача данных аккаунта, настроек, статистики или журналов разработчику не предусмотрена. Самостоятельная публикация сведений в GitHub issue или их отправка для диагностики — отдельное действие пользователя.

## 6. Хранение и управление данными

Настройки, каталог, расписание, служебные результаты, счётчики и журнал хранятся в `chrome.storage.local` в профиле браузера. Расширение не использует `chrome.storage.sync` и не отправляет эти записи в собственное облачное хранилище.

Каталог обновляется при чтении профиля. При смене аккаунта сроки прежнего продавца не применяются к новому. Служебная запись запуска удаляется при завершении или обработке истёкшего запуска. Для остальных локальных записей нет общего срока автоматического удаления: они сохраняются до обновления или удаления пользователем; журнал ограничен 200 записями.

Пользователь может:

- включать и выключать автоподнятие, автотикеты, внешний фон и уведомления;
- очищать локальный журнал кнопкой «Очистить»;
- удалять сохранённый шаблон обращения соответствующей кнопкой;
- очищать локальные настройки, каталог, расписание, счётчики и журнал через «Настройки» → «Сброс данных»;
- удалить Расширение средствами браузера.

После сброса следует обновить открытые вкладки Starvell: очистка хранилища сама по себе не очищает память загруженной страницы, где могли остаться ключ и результаты статистики. Сброс не удаляет cookie сайта, содержимое системного буфера обмена, заказы или отправленные обращения на стороне Starvell. Сессию можно завершить на сайте, а cookie удалить средствами браузера; буфер обмена очищается отдельно.

После удаления Расширения следует также обновить или закрыть открытые вкладки, чтобы завершить работу ранее загруженных скриптов.

## 7. Разрешения Расширения

| Разрешение | Использование |
|---|---|
| `storage` | Локальные настройки, каталог, расписание, счётчики и журнал |
| `alarms` | Планирование проверок и поднятия, восстановление расписания |
| `notifications` | Уведомления о результатах и ошибках, если они включены |
| `cookies` | Чтение сессионной cookie Starvell для проверки авторизации и Session Key |
| `scripting` | Подмена звуков сайта выбранными звуками из файлов Расширения |
| Доступ к `https://starvell.com/*` и `https://*.starvell.com/*` | Работа с сайтом и его сессией; интерфейс внедряется на страницах `starvell.com` |

Расширение не запрашивает отдельные разрешения на историю браузера или геолокацию. Звуковые пресеты поставляются в составе Расширения.

## 8. Изменения политики

Политика обновляется при изменении обработки данных или функций Расширения. Актуальный текст публикуется в репозитории проекта; версия и дата обновления указаны в начале документа.

## 9. Контакты

Вопросы о работе Расширения и обработке данных можно направить через [GitHub Issues проекта Starvell Helper](https://github.com/Hilongod/starvell-helper/issues).

Не публикуйте сессионный ключ или другие секреты в открытых обращениях.
