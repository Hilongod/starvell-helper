# Политика конфиденциальности расширения Starvell Helper

_Дата вступления в силу: 7 сентября 2026 г._

## 1. Введение

Расширение **Starvell Helper** (далее — «Расширение») разработано для автоматизации действий на сайте `starvell.com`. Расширение не собирает, не хранит и не передаёт личные данные пользователей. Вся информация, необходимая для работы, сохраняется исключительно в локальном хранилище вашего браузера.

Настоящая политика конфиденциальности описывает, какие данные обрабатываются, как они используются и какие меры безопасности применяются.

## 2. Какие данные собираются

Расширение **НЕ собирает**:
- личную информацию (имя, адрес, телефон, адрес электронной почты, возраст);
- финансовые или платёжные данные;
- данные для аутентификации (пароли, PIN-коды, секретные вопросы);
- историю посещений или поиска за пределами `starvell.com`;
- содержимое сообщений, чатов или любые другие личные коммуникации;
- данные о местоположении.

Расширение **обрабатывает** (но не сохраняет и не передаёт) следующие данные исключительно для выполнения своих функций:

- **Сессионная cookie (`session`)** – используется для авторизации запросов к API Starvell от имени пользователя. Расширение читает эту cookie только для отображения в интерфейсе (раздел «Session Key») и для проверки статуса авторизации. Cookie не сохраняется в хранилище расширения и не передаётся третьим лицам.
- **Настройки пользователя** – такие как включение/выключение автоподнятия, параметры кастомного фона (ссылка на изображение, прозрачность), настройки звуков, цвета свечения и т.д. Все настройки хранятся локально в `chrome.storage.local` и доступны только в вашем браузере.
- **Статистика и логи** – счётчики поднятий, ошибок, история событий. Эти данные также хранятся локально и используются только для отображения в интерфейсе расширения.

## 3. Как используются данные

Все данные используются **исключительно** для обеспечения работы функций расширения:

- Автоподнятие лотов – отправка запросов к API `/api/offers/bump` с параметрами, полученными из профиля пользователя.
- Отображение статистики продаж – загрузка данных о заказах через API `/api/orders/list`.
- Автотикеты – поиск заказов со статусом `CREATED` и создание обращений в поддержку через API `/api/support/create`.
- Кастомизация сайта – применение фона, звуков и свечения на основе пользовательских настроек.
- Отображение Session Key – для удобства пользователей, которые используют ключ в сторонних приложениях.

Все API-запросы направляются только на домен `starvell.com` и используют вашу активную сессию в браузере. Никакие данные не передаются на сторонние серверы.

## 4. Передача данных третьим лицам

Расширение **не передаёт** пользовательские данные третьим лицам. Все данные остаются на вашем устройстве и используются только локально.

## 5. Хранение данных

Все данные, обрабатываемые расширением, хранятся **локально** в вашем браузере с использованием `chrome.storage.local`. Они не покидают ваше устройство и не синхронизируются с облачными сервисами. Вы можете удалить все сохранённые данные в любой момент через раздел «Настройки» → «Сброс данных» в интерфейсе расширения.

## 6. Безопасность

Расширение не использует внешние серверы, аналитику или трекеры. Все операции выполняются в среде вашего браузера. Для доступа к API Starvell используются ваши сессионные cookie, которые автоматически передаются браузером. Расширение не запрашивает и не хранит пароли или другие учётные данные.

## 7. Изменения политики
