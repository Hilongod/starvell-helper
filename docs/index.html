⭐ Starvell Helper

Расширение для браузера Chrome для торговой площадки Starvell.

Что умеет:

  • 🚀 Автоподнятие лотов — включается одной галочкой, интервал от 5 до 120 минут
  • 🎨 Кастомный полупрозрачный фон с blur-эффектом

Установка:

  1. Скачай расширение из Chrome Web Store
  2. Открой starvell.com
  3. Нажми на иконку расширения и настрой под себя
