## 🛠️ Исправления в v2.1.4

- Автоподнятие работает для всех игр и сервисов из профиля текущего продавца: по одному POST на `gameId` с актуальным массивом `categoryIds`.
- Плановая проверка профиля назначается раз в **30 минут**, в том числе при долгом cooldown. Перед поднятием также читается свежий профиль с `cache: no-store`; срок поднятия не сдвигается до следующей плановой проверки.
- Состав игр и категорий сохраняется и обновляется автоматически. Новая игра попадает в очередь при ближайшей проверке; новая категория уже известной игры включается в её следующий разрешённый запрос.
- Новые лоты в существующей категории охватываются запросом к этой категории. Удалённые игры и категории исключаются из следующих запросов.
- Срок поднятия сохраняется отдельно для каждой игры. Базовый интервал по умолчанию — **2 часа**, после успеха к нему добавляется **1 минута запаса**. Таймер сразу показывает полный срок **02:01:00**. При cooldown применяется только серверное `retryAfterSeconds + 60` секунд; дополнительный базовый интервал поверх cooldown не прибавляется. Общий HTTP 429 временно останавливает POST ко всем играм, учитывая `Retry-After`.
- При первом запуске обновления прежнее стандартное значение 30 минут заменяется на 2 часа. Другие выбранные интервалы и серверные сроки сохраняются. Если после обновления выбрать 30 минут вручную, выбор сохранится.
- Таймеры панели используют формат часы:минуты:секунды и раздельно показывают следующее поднятие и следующую проверку профиля.
- Учитываются категории из актуальной выдачи профиля и его фильтров, включая категории за пределами первой страницы карточек.
- При смене аккаунта состав предложений и сроки ожидания обновляются по владельцу свежего ответа сайта.
- Secret Key по-прежнему извлекается из cookie через background. Исправлена ошибка области видимости функции обратной связи; ключ не печатается в консоль. Автоподнятие использует браузерную сессию и не требует получения текста ключа.
- Кнопка S создана в отдельном узле с Shadow DOM вне разметки React. Скрипты интерфейса запускаются после построения документа; панель находится внутри body.
- Перед запуском проверяется готовность и версия протокола вкладки. При потере подтверждения второй POST из другой вкладки не запускается.
- Необработанные игры получают приоритет после истечения времени длинного запуска.

**Проверка:** 58 тестов прошли на Node.js v24.19.0. HTTP, Chrome API и DOM имитируются; живое поднятие в аккаунте и повторная проверка React-гидратации на Starvell не выполнялись.

### Установка патча 2.1.4

1. Распакуй `starvell-helper-2.1.4-patch.zip` поверх существующей папки расширения, где находится его `manifest.json`, с заменой файлов.
2. Открой `chrome://extensions/` и нажми «Перезагрузить» у существующей установки Starvell Helper.
3. Обнови все вкладки Starvell. В панели и консоли должна отображаться версия 2.1.4.
4. Включи автоподнятие. Список игр/сервисов и категорий берётся из твоего свежего профиля.

Это патч для существующей установки. Иконки, звуки и остальные ресурсы используются из неё.

[Изменение интервалов и проверка времени](starvell-helper-2.1.4-update.md). Тесты находятся в `tests/auto-boost.test.cjs`, протокол проверок — в `tests/RESULTS.txt`.

Запуск тестов из папки расширения:

```bash
node tests/auto-boost.test.cjs
```

### 🚀 Адаптивное автоподнятие лотов

Расширение автоматически читает данные из вашего профиля: определяет игры (приложения) и категории с активными лотами.

- Группирует лоты по играм и отправляет **один запрос на игру**; категории этой игры передаются массивом `categoryIds`
- При успешном HTTP-ответе без ошибки в JSON — лоты подняты, уведомление в браузере
- При ошибке 429 (Rate Limit) — автоматически забирает время ожидания из ответа сервера, переводит в минуты, добавляет +1 минуту запаса и перепланирует следующий подъём
- Управление: тумблер **вкл/выкл**, выбор базового интервала и «Поднять сейчас». Серверный cooldown учитывается автоматически.

> ℹ️ Базовый интервал по умолчанию — 2 часа + 1 минута запаса. Серверное ожидание — сообщённый остаток + 1 минута. Для примера: успешное поднятие в 14:00 назначает следующее на 16:01. Проверка профиля раз в 30 минут этот срок не переносит. «Поднять сейчас» учитывает известный cooldown.

## 🚀 Возможности

### 🚀 Автоподнятие лотов
- Автоматически читает все активные лоты из профиля
- Поднимает **все игры** — по одному запросу на игру
- **Адаптивный интервал** — система сама подбирает время с учётом cooldown
- Работает в фоне через Chrome Alarms API — даже если вкладка не активна
- Умная обработка `429 (Too Many Requests)`: перехват Retry-After, перепланирование
- Счётчики: поднятий всего / за сессию / ошибок
- Уведомления в браузере после каждого подъёма

### 🎫 Автотикеты *(бета)*
- Находит неподтверждённые заказы (статус `CREATED`) старше заданного срока
- Группирует заказы **по дню создания** — один тикет на один день
- Автоматически формирует список номеров заказов в тикете
- Настраиваемый период (3 / 7 / 14 / 30 дней)
- Ручная отправка кнопкой «Отправить тикет сейчас»
- Проверка расписания раз в сутки

### 📊 Статистика продаж
- Текущий баланс кошелька и общая сумма заработанного
- Количество успешных заказов и возвратов
- Средний чек, уникальные покупатели
- Топ категория и топ покупатель по количеству продаж
- **График продаж** за последние 14 дней с всплывающими подсказками

### 📋 Лог событий
- История всех действий расширения с временными метками
- Цветовая индикация: успех / предупреждение / ошибка
- Кнопка очистки лога

### 🔑 Session Key
- Отображение сессионной cookie
- Копирование в буфер обмена

### 🔊 Кастомные звуки
- Замена звуков новых сообщений (3 пресета + mute)
- Замена звуков новых заказов (3 пресета + mute)

### ✨ Свечение блоков
- Неоновая подсветка основных контейнеров сайта
- Настройка цвета (11 цветов) и интенсивности

### 🎨 Кастомный фон
- Устанавливает любое изображение как фон сайта по прямой ссылке (включая `.gif`)
- Предпросмотр изображения прямо в интерфейсе
- Ползунок прозрачности
- 4 встроенных пресета

### ⚙️ Настройки
- Включение/выключение уведомлений браузера
- Сброс всех сохранённых данных

## ⬇️ Установка

### 1. Скачай расширение

Нажми **Releases → Assets → starvell-helper.zip** и распакуй в любую папку.

Или через Git:
```bash
git clone https://github.com/Hilongod/starvell-helper.git
```

### 2. Открой управление расширениями

```
chrome://extensions/
```

### 3. Включи режим разработчика

В правом верхнем углу включи тумблер **«Режим разработчика»**.

### 4. Загрузи расширение

Нажми **«Загрузить распакованное»** и выбери папку с расширением.

### 5. Готово

Кнопка **S** появится прямо в навбаре на starvell.com. Кликни по иконке расширения в Chrome — откроется полная панель инструментов.

> ⚠️ Расширение работает только в браузере Chrome. Для поднятия нужна открытая вкладка Starvell; она может быть неактивной.

---

### 🚀 Автоподнятие лотов

1. Открой **starvell.com** и войди в аккаунт
2. Перейди в раздел **Автоподнятие**
3. Просто включи тумблер **«Включить автоподнятие»**

Всё. Расширение само найдёт все твои лоты, определит игры и категории, и будет поднимать их с адаптивным интервалом.

> ⚠️ При обнаружении cooldown (429) расширение автоматически перепланирует подъём, учитывая время ожидания от сервера. Тебе не нужно ничего настраивать.

---

### 🎫 Автотикеты *(бета)*

1. Перейди в раздел **Автотикеты**
2. Выбери период ожидания (сколько дней ждать подтверждения — по умолчанию 7)
3. Включи **«Включить автотикеты»**

Расширение раз в сутки проверит заказы и отправит тикеты по тем, что зависли. Можно отправить и вручную — кнопка **«🎫 Отправить тикет сейчас»**.

---

### 📊 Статистика продаж

Перейди в раздел **Статистика** и нажми **«🔄 Загрузить статистику»** — данные загрузятся со страниц «Мои продажи» и «Кошелёк».

---

### 🎨 Кастомный фон

1. Перейди в раздел **Кастомный фон**
2. Включи тумблер
3. Вставь прямую ссылку на изображение или выбери пресет
4. Настрой ползунок **«Проявление»**
5. Нажми **«✓ Применить фон»**

---

### 🔊 Кастомные звуки

1. Перейди в раздел **Звуки**
2. Выбери звук для сообщений и/или заказов
3. Нажми **«▶ Прослушать»** для проверки
4. Звук применится автоматически

---

### ✨ Свечение блоков

1. Перейди в раздел **Свечение**
2. Включи тумблер
3. Выбери цвет и интенсивность
4. Нажми **«✨ Применить»**

---

### 🔑 Session Key

1. Перейди в раздел **Session Key**
2. Нажми **«👁 Показать»** чтобы увидеть ключ
3. Нажми **«📋 Скопировать»** чтобы скопировать в буфер обмена

> 🔐 **Внимание:** Никому не передавайте этот ключ!

## ❓ Частые вопросы

**Почему Rate limit / ошибка 429?**  
Расширение само обрабатывает это: перехватывает время ожидания из ответа и перепланирует подъём. Тебе не нужно ничего менять.

**Расширение не видит мои лоты?**  
В v2.1.4 поддерживается актуальная схема профиля. Открой свою страницу профиля и проверь лог: ошибка загрузки профиля отличается от отсутствия активных лотов.

**Автотикет не отправился / «Неподтверждённых заказов нет»?**  
Значит нет заказов со статусом `CREATED` старше выбранного периода. Проверь период в настройках.

**Сайт показывает 404 при переходах?**  
Проверь другие расширения в Chrome — особенно блокировщики рекламы и антидетект. Они инжектят свой код и ломают роутинг Starvell. Отключай по одному, чтобы найти виновника.

**После перезагрузки браузера автоподнятие выключилось?**  
Настройки сохраняются в chrome.storage.local. В v2.1.4 таймер восстанавливается при запуске браузера, обновлении расширения и запуске service worker. Если вкладки сайта были открыты до обновления расширения, обнови их.

**Фон не применяется?**  
Убедись что ты на starvell.com, обнови страницу (F5) и примени фон снова.

**Звуки не работают?**  
Проверь, что выбран не режим «Без звука» и что на странице разрешено воспроизведение звуков (в Chrome настройки сайта).

**Безопасно ли это?**  
Расширение работает только на starvell.com, не собирает данные и не отправляет ничего на сторонние серверы. Все запросы идут напрямую к API Starvell от твоего имени. Session Key отображается только тебе и хранится локально.
