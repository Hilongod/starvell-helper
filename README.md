## ⚡ Возможности

### 🚀 Автоподнятие лотов
- Автоматически отправляет запрос на поднятие всех лотов через официальный API Starvell
- Настраиваемый интервал: от 5 минут до 2 часов
- Работает в фоне — даже если вкладка не активна (через Chrome Alarms API)
- Умный перехват: при первом ручном нажатии «Поднять» на сайте — запоминает все твои категории и использует их для автоподнятия
- Уведомления в браузере после каждого подъёма

### 🎨 Кастомный фон
- Устанавливает любое изображение как фон сайта по прямой ссылке (в том числе и анимированные фото .gif)
- Ползунок прозрачности — настраивай яркость фона под себя
- 4 встроенных пресета (Аниме v1, Аниме v2, Лес, Горы)
- Фон не ломает вёрстку и не затрагивает карточки и элементы сайта
- Настройки сохраняются между сессиями

## ⬇️ Установка

Расширение устанавливается вручную в режиме разработчика — это займёт меньше минуты.

### 1. Скачай расширение

Нажми кнопку **Code → Download ZIP** на этой странице и распакуй архив в любую папку.

Или через Git:
```bash
git clone https://github.com/Hilongod/starvell-helper.git
```

### 2. Открой управление расширениями в Chrome

Перейди по адресу:
```
chrome://extensions/
```

Или: **Меню Chrome → Расширения → Управление расширениями**

> ⚠️ Важно расширение функционирует только в браузере chrome, другие не тестил если сможете выгрузить файл и будет работать делайте

### 3. Включи режим разработчика

В правом верхнем углу страницы включи тумблер **«Режим разработчика»**.

### 4. Загрузи расширение

Нажми кнопку **«Загрузить распакованное»** и выбери папку с расширением.

### 5. Готово

Иконка **⭐ S** появится в панели расширений Chrome. Если не видно — нажми на иконку пазла 🧩 рядом с адресной строкой и закрепи расширение.

## 🚀 Как пользоваться

### Автоподнятие лотов

1. Открой **starvell.com** и войди в свой аккаунт
2. Нажми иконку расширения ⭐
3. **Первый запуск:** нажми кнопку «Поднять предложения» на сайте вручную один раз — расширение перехватит твои категории и запомнит их
4. В расширении выбери интервал и включи **«Автоподнятие»**
5. Всё — лоты будут подниматься автоматически по расписанию

> ⚠️ Сервер Starvell разрешает поднятие раз в **2 часа и более**. Рекомендуемый интервал — **30 минут**. При более частых попытках сервер вернёт ошибку 400 — это нормально, расширение просто подождёт следующего цикла.

> ⚠️ Важный момент расширение перехватывает только категории одной игры или сервиса (т.е подняли категории **roblox** будут подыматься **roblox**, подняли категории **telegram** будут подыматься категории **telegram**).

### Кастомный фон

1. Нажми иконку расширения ⭐
2. В секции **«Кастомный фон»** включи тумблер
3. Вставь прямую ссылку на изображение или выбери один из пресетов (поддерживаются анимированные фото .gif)
4. Настрой ползунок **«Проявление»** под себя
5. Нажми **«✓ Применить фон»**

> Прямая ссылка — это ссылка, которая заканчивается на `.jpg`, `.png`, `.webp`, `.gif` и открывает только картинку в браузере.

## ❓ Частые вопросы

**Почему появляется ошибка 400?**
Это значит что время с последнего подъёма ещё не вышло (меньше 2, 4 и более часов). Расширение попробует снова при следующем срабатывании.

**Фон не применяется — что делать?**
Убедись что ты на сайте starvell.com, обнови страницу (F5) и попробуй применить фон снова.

**После перезагрузки браузера автоподнятие выключилось?**
Включи его снова в popup — расширение восстановит таймер автоматически. Chrome не сохраняет состояние тумблера между запусками.

**Расширение не видит мои лоты?**
Нажми кнопку «Поднять предложения» вручную один раз прямо на сайте Starvell — после этого расширение запомнит все твои категории.

**Безопасно ли это?**
Расширение работает только на starvell.com, не собирает никаких данных, не отправляет ничего на сторонние серверы. Все запросы идут напрямую к API Starvell от твоего имени — точно так же, как если бы ты нажимал кнопку вручную.
